## 关于 ECutPro

ECutPro（E剪Pro）与传统视频编辑软件不同，**专注于批量处理和自动化**。你只需导入视频、设置参数，即可一键处理成百上千个视频文件，无需逐个手动操作。

**适用人群：**
- 📱 短视频创作者（抖音、快手、B站等平台）
- 🎞️ 需要批量差异化出片的运营团队
- ✂️ 影视混剪爱好者

**支持平台：**

| 系统 | 最低版本 |
|------|----------|
| Windows | Windows 10 64位 |
| macOS | m && intel 已上线 |

**核心优势：**

| 传统剪辑软件 | ECutPro |
|-------------|---------|
| 手动逐个处理 | 批量自动化处理 |
| 操作复杂，学习成本高 | 三步上手，新手友好 |
| 单次只能导出一个视频 | 一次处理成百上千个视频 |
| 不支持批量差异化 | 智能差异化，防重复检测 |

## 核心功能

### 一、素材管理

#### 1. 导入视频
- 支持拖拽批量导入（MP4、AVI、MOV、MKV、FLV 等主流格式）
- 支持文件夹整体导入，快速加载大量素材

#### 2. 查看视频信息
- 导入后可查看每个视频的分辨率、时长、编码格式、帧率等详细信息
- 方便筛选和管理素材质量

#### 3. 设置输出位置
- 自定义视频输出目录
- 支持按日期、任务名等规则自动命名输出文件

#### 4. 裁剪画面
- 支持自由裁剪画面区域
- 可预设常用裁剪比例（16:9、9:16、1:1、4:3 等）

---

### 二、效果设置

> 所有效果均支持批量应用，一次配置、批量生效。

#### 🎞️ 视频变速
- 支持慢动作与快进效果
- 可按片段设置不同速度，制作节奏感强的混剪视频

#### 🔲 水印处理
- **添加水印：** 支持文字水印、图片水印，可自定义位置、大小、透明度
- **去除水印：** 智能识别并去除原视频水印（仅限个人学习使用，请遵守版权法规）

#### 📝 添加文本
- 支持自定义字体、颜色、大小、位置
- 支持文字动画效果（弹幕、淡入淡出、打字机等）
- 可批量为所有视频添加统一文字内容

#### 🖼️ 画中画
- 支持在主视频上叠加第二路视频画面
- 可调整子画面的大小、位置与透明度

#### ✨ 入场效果
- 内置多种开场动画效果
- 自定义入场时长与触发时机

#### 🔄 旋转与镜像
- 支持视频旋转（90°/180°/270°）
- 支持水平/垂直镜像翻转

#### 🎨 画面调整
- 亮度、对比度、饱和度、色温调节
- 支持预设滤镜快速应用

#### 🎬 视频帧操作
- 支持提取指定帧为图片
- 支持帧率转换（补帧/降帧）

#### 🎵 音频设置
- 音量调节与音频混合
- 支持背景音乐添加（MP3、WAV、FLAC）
- 智能淡入淡出与节奏匹配

#### 🔮 像素融合
- 特殊转场与融合效果
- 打造电影质感的画面过渡

#### 🔍 动态缩放
- 模拟镜头推拉效果（Ken Burns 效果）
- 让静态画面也具有动感

#### ✂️ 视频混剪
- 自动将多段素材智能拼接
- 支持按时长、节奏、场景自动切分重组
- 批量生成差异化成片，防平台查重

---

### 三、输出设置

#### 📐 画面参数
- 分辨率：480P / 720P / 1080P / 2K / 4K
- 帧率：24fps / 30fps / 60fps
- 比例：16:9 / 9:16 / 1:1 / 4:3 等

#### 📁 文件参数
- 输出格式：MP4、MOV、AVI、MKV
- 视频编码：H.264 / H.265（HEVC）
- 码率：自定义码率，平衡画质与文件大小

#### ⚡ 性能参数
- 最大并发处理任务数设置
- GPU 硬件加速开关（支持 NVIDIA / AMD / Intel 核显）
- 后台低优先级运行模式

#### 🧬 裂变功能
- 批量生成多个差异化版本
- 随机调整画面参数、音频、文字等，实现视频"裂变"
- 有效规避平台重复视频检测机制

---

### 四、开始处理

#### 启动处理
点击底部「**开始处理**」按钮，软件会按顺序依次处理所有视频任务。

#### 查看进度
- 实时显示每个任务的处理进度与预计剩余时间
- 已完成数量与总任务数实时更新

#### 取消处理
点击「**取消**」可随时中断处理，**已完成的视频文件会保留**，不会丢失。

#### 处理状态说明

| 状态标识 | 含义 |
|----------|------|
| 等待中 | 任务在队列中等待处理 |
| 处理中 | 当前正在渲染输出 |
| 已完成 | 视频已成功输出到指定目录 |
| 失败 | 处理出错，可查看错误日志 |

## 常见问题

**Q: ECutPro 和普通剪辑软件有什么区别？**
> A: ECutPro 专注于**批量自动化处理**，不适合精细化的单视频剪辑，但处理大量视频时效率远超传统软件。如果你需要批量出片，ECutPro 是首选。

**Q: 支持哪些输入视频格式？**
> A: 支持 MP4、AVI、MOV、MKV、FLV、WMV、TS 等主流格式。

**Q: 批量处理时电脑卡顿怎么办？**
> A: 可在「输出设置 → 性能参数」中降低最大并发任务数，或开启「后台低优先级模式」，减少对日常使用的影响。

**Q: 裂变功能生成的视频真的能过平台检测吗？**
> A: 裂变功能通过调整多维度参数制造差异化，对常规的重复视频检测有较好效果，但平台算法持续更新，建议配合其他差异化手段使用。

**Q: 导出的视频体积过大？**
> A: 在「输出设置 → 文件参数」中选择 H.265 编码器，并适当降低码率，可在保证画质的同时显著减小文件体积。

**Q: 去水印功能违法吗？**
> A: 本工具的水印去除功能**仅供个人学习研究使用**，请勿将处理结果用于商业用途，务必遵守相关版权法律法规。

**Q: 处理失败了怎么办？**
> A: 点击失败任务查看错误日志，常见原因包括：视频文件损坏、格式不支持、磁盘空间不足。解决对应问题后重新添加任务即可。
